# 生产代码中文注释设计

## 目标

为项目自有的生产代码补充中文注释，帮助读者理解文件职责、核心流程、状态变化、并发约束、资源生命周期、网络协议和 JNI 边界，不改变任何运行行为。

## 范围

- 注释 `app/src/main` 中的 Kotlin、C++ 与 CMake 文件。
- 注释 `whisper-native/src/main` 中的 C++ 与 CMake 文件。
- 不修改 `src/test`、`src/androidTest`、`third_party`、资源 XML、模型文件和生成目录。

## 注释策略

- 在类、接口、状态机、数据模型和关键函数前添加职责说明。
- 在不容易直接看懂的并发、取消、generation 过滤、原子发布、TCP 分帧、模型加载和 JNI 转换代码旁添加原因说明。
- 对 Compose 大组件说明其展示内容和交互作用，但不逐项解释颜色、间距和普通赋值。
- CMake 注释说明第三方库的裁剪选项、模块隔离原因和最终链接关系。
- 使用简洁中文，避免把代码逐行翻译成自然语言，也不保留与实现重复或容易过期的描述。

## 行为与验证

- 本次只增加注释，不调整函数签名、常量、控制流或配置值。
- 不新增或修改测试代码。
- 修改后检查差异，确认只有注释发生变化；随后运行现有单元测试和 Android 构建验证语法及工程配置。
