# 参数数值原位编辑设计

## 目标

让检测参数与剔除参数中的八个整数值可以点击并通过系统数字键盘直接输入，同时保留现有滑块、减号和加号操作。

## 交互

- 点击步进器中间的数值后，数值原位进入编辑状态并显示数字键盘。
- 获得焦点时选中当前值，便于用户直接覆盖。
- 点击键盘“完成”或点击控件外部时提交输入。
- 合法整数按原值提交，不按滑块或加减按钮的步长取整。
- 超出参数允许范围时限制到最近的边界值。
- 空字符串、非整数或超出 `Int` 表示范围的内容恢复为提交前的参数值。
- 提交后数值、滑块和后续发送的 JSON 使用同一个整数状态。

## 范围

| 参数 | 范围 |
| --- | --- |
| Lv1 灵敏度 | 0..100 |
| Lv1 强度 | 0..120 |
| Lv1 浓淡 | 0..100 |
| 最小面积 | 0..10000 |
| Lv2 强度 | 0..120 |
| Lv3 强度 | 0..100 |
| 动作持续 | 0..2000 |
| 剔除延时 | 0..1500 |

## 结构

`commitParameterInput(text, previousValue, range)` 是不依赖 Compose 的纯 Kotlin 函数，负责解析、回退和范围限制。`ParameterControlRow` 把整数值与范围传给 `Stepper`；`Stepper` 管理临时文本、焦点、全选和 IME 提交，并只通过现有 `onValueChange` 更新页面状态。

## 验证

- JVM 单元测试覆盖合法值、非步长值、上下越界、空值、非数字和整数溢出。
- 编译 Compose 代码并运行现有全部 JVM 测试，确认 TCP、语音和参数发送行为无回归。
